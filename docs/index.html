CODEX 重置预测看板 · WINDOWS

Codex 额度与重置预告

一款 Windows 桌面看板，用来查看 Codex 剩余额度、跟踪五个网站的重置预告，并比较历史重置时间。 有具体时间的重置消息，会自动弹出 Windows 通知。

下载 Windows 版在 GitHub 查看 ↗

Windows 10/11 · 软件中英双语 · GPL-3.0

安装

安装 Windows 版

  1. 在 Releases 选择安装版或便携版。
  2. 打开即可查看重置消息，在设置中选择语言和字号。
  3. 看板已内置官方 Codex，已有本机 Codex 的 ChatGPT 登录会自动接入额度；未登录时按提示授权。
