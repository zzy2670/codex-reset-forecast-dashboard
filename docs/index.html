INSTALLATION

Get the dashboard running.

  1. Download the installer or portable version from Releases.
  2. Open the dashboard to see reset announcements. Choose your language and text size in Settings.
  3. To show personal quota, install the official Codex CLI and sign in with codex login.

The installation guide covers CLI setup, Windows publisher prompts and where settings are saved.
